# MATLAB Web — محیط متلب آنلاین برای کلاس

سایتی شبیه MATLAB R2021b که کاملاً داخل مرورگر اجرا می‌شود و برای ذخیره کدها از **Supabase** (رایگان) استفاده می‌کند.

- دانشجو با **شماره دانشجویی و رمز عبور** ثبت‌نام می‌کند و کدهایش خودکار ذخیره می‌شود.
- **پنل استاد** همه دانشجوها، همه فایل‌ها (با زمان ساخت و آخرین ویرایش)، اجرای کد هر دانشجو، یادداشت برای هر فایل، تغییر رمز دانشجو و دانلود همه کدها (zip) را دارد.
- **فایل‌های درس** (مثل `ECG_Data.mat` و `penguins_size.csv`) را استاد یک بار بارگذاری می‌کند و همه دانشجوها از آن استفاده می‌کنند.
- همه کوییزها و تمرین‌های جزوه در زبانه **ASSIGNMENTS** آماده است.

---

## راه‌اندازی (حدود ۱۵ دقیقه، یک بار)

### ۱) ساخت پروژه Supabase
1. به <https://supabase.com> بروید و با ایمیل یا GitHub ثبت‌نام کنید.
2. **New project** بزنید. یک نام (مثلاً `matlab-class`)، یک رمز دیتابیس و منطقه (Region) نزدیک مثل **Frankfurt** انتخاب کنید. چند دقیقه صبر کنید تا پروژه ساخته شود.

### ۲) ساخت جدول‌ها
1. از منوی چپ **SQL Editor** ← **New query** را باز کنید.
2. کل محتوای فایل `supabase/schema.sql` را کپی کنید، آنجا بچسبانید و **Run** بزنید. باید پیام `Success` بیاید.

### ۳) خاموش کردن تأیید ایمیل
چون دانشجوها ایمیل وارد نمی‌کنند، این گزینه باید خاموش باشد:
**Authentication** ← **Sign In / Providers** ← **Email** ← گزینه **Confirm email** را خاموش کنید و **Save** بزنید.
(گزینه **Allow new users to sign up** باید روشن بماند.)

### ۴) وصل کردن سایت به Supabase
1. **Project Settings** ← **API** (یا **Data API**) را باز کنید.
2. **Project URL** و کلید **anon public** را کپی کنید.
3. فایل `public/config.js` را باز کنید و این دو مقدار را به جای `YOUR_SUPABASE_URL` و `YOUR_SUPABASE_ANON_KEY` بگذارید.

> کلید anon عمومی است و قرار دادنش در سایت امن است؛ دسترسی‌ها با قوانین امنیتی دیتابیس (RLS) کنترل می‌شود. **کلید `service_role` را هرگز جایی نگذارید.**

### ۵) انتشار سایت (رایگان)
ساده‌ترین راه **Netlify Drop** است:
1. به <https://app.netlify.com/drop> بروید (ثبت‌نام رایگان).
2. **پوشه `public`** را بکشید و داخل صفحه رها کنید. چند ثانیه بعد آدرس سایت (مثل `https://xxxx.netlify.app`) را می‌دهد.
3. از **Site configuration** می‌توانید نام آدرس را عوض کنید.

راه دیگر **GitHub Pages** است: محتوای پوشه `public` را در یک مخزن بگذارید و Pages را فعال کنید. فایل `coi-serviceworker.js` تنظیمات لازم را خودش انجام می‌دهد (در اولین بازدید، صفحه یک بار خودکار رفرش می‌شود).

### ۶) ساخت حساب استاد
1. وارد سایت شوید و مثل یک دانشجو **ثبت‌نام** کنید (در قسمت شماره دانشجویی مثلاً کد پرسنلی یا `teacher` را بنویسید).
2. در Supabase به **SQL Editor** بروید و این را اجرا کنید (به جای `teacher` همان شناسه خودتان را بگذارید):
   ```sql
   update public.profiles set role = 'teacher' where student_id = 'teacher';
   ```
3. یک بار خارج و دوباره وارد شوید؛ پنل استاد باز می‌شود. دکمه «محیط متلب» در پنل، خود محیط برنامه‌نویسی را برای شما باز می‌کند.

### ۷) بارگذاری فایل‌های درس
در پنل استاد ← **فایل‌های درس**، فایل‌هایی مثل `ECG_Data.mat` و `penguins_size.csv` را بارگذاری کنید. دانشجوها در کد خود مستقیم می‌نویسند:
```matlab
load('ECG_Data.mat')
T = readtable('penguins_size.csv');
```

## نکته‌های مهم

- **فراموشی رمز:** دانشجو ایمیل ندارد؛ استاد از پنل (صفحه دانشجو ← «تغییر رمز دانشجو») رمز جدید می‌گذارد.
- **غیرفعال شدن پروژه رایگان:** Supabase پروژه رایگانی را که **۷ روز** هیچ استفاده‌ای نداشته باشد موقتاً متوقف می‌کند (مثلاً در تعطیلات). در این صورت وارد داشبورد Supabase شوید و **Restore project** را بزنید؛ اطلاعات پاک نمی‌شود.
- **ظرفیت رایگان:** ۵۰۰ مگابایت دیتابیس؛ برای چند صد دانشجو و هزاران فایل کد کافی است. فایل‌های بزرگ‌تر از ۱۵ مگابایت قبول نمی‌شوند.
- **اینترنت ایران:** قبل از شروع کلاس، سایت را با اینترنت چند دانشجو (اپراتورهای مختلف) امتحان کنید. اگر Supabase در دسترس نبود، کدها موقتاً در مرورگر ذخیره و بعداً خودکار ارسال می‌شوند.
- **مرورگر:** Chrome، Edge یا Firefox جدید. روی موبایل هم کار می‌کند ولی برای کار جدی لپ‌تاپ بهتر است.
- **حالت آزمایشی:** تا وقتی `config.js` پر نشده، سایت در حالت آزمایشی کار می‌کند و فایل‌ها فقط در همان مرورگر ذخیره می‌شوند.

## چه چیزهایی پشتیبانی می‌شود

همه مباحث جزوه: عملیات ماتریسی و آرایه‌ای، توابع ریاضی، `format`، رشته‌ها و `sprintf/fprintf/num2str/input`، cell و struct، رسم نمودار (`plot`، `subplot`، `hold`، `legend`، `semilogx/y`، `plotyy`، `mesh/surf/contour`، `plot3`، `fplot`، `area`، `bar`، `histogram`، `boxplot`، `saveas`)، چندجمله‌ای‌ها و `residue`، محاسبات نمادین (`syms`، `diff`، `int`، `solve`، `dsolve`، `limit`، `simplify`، `factor`، `numden`، `finverse`)، کنترل جریان، توابع در فایل و Anonymous Function، فایل‌های `.mat` (نسخه ۷ و قبل‌تر)، CSV، Excel، `readtable` و آمار (`mean`، `std`، `ttest2`، `vartest2`، `kstest2`، `ranksum`، ...).

پیام‌های خطا و شکل خروجی‌ها مثل MATLAB R2021b است. فایل‌های MAT نسخه 7.3 (HDF5) پشتیبانی نمی‌شوند؛ در متلب با `save('file.mat','-v7')` ذخیره کنید.

## برای توسعه‌دهنده

```bash
npm install          # یک بار
npm run build        # ساخت public/dist
node serve.mjs       # سرور محلی روی http://localhost:8080
npm test             # تست‌های رگرسیون موتور متلب (test/cases → test/golden)
```

- `src/engine/` موتور متلب (lexer، parser، مفسر، توابع داخلی) که در یک Web Worker اجرا می‌شود.
- `src/app/` رابط کاربری دانشجو (`main.js`) و پنل استاد (`teacher.js`).
- `supabase/schema.sql` جدول‌ها و قوانین امنیتی.
